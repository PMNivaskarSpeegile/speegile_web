Project Overview

What Was Built

A fully responsive, animated multi-page website for Speegile — delivered as a single HTML file with modular JSX component files.

Structure

6-Page Single Page App

Home, Human Capital Solutions, Analytics Solutions, Why Speegile, About Us, and Contact — all within one HTML shell using hash-based routing (#/page-name) for instant navigation without page reloads.

Delivery Format

Modular File Architecture

The project is split across 9 files: one main index.html, two component files (Navbar, Footer), five page files, and one animation polyfill — each loaded as a Babel JSX script tag.

Responsiveness

Mobile-First Design

All layouts use CSS Grid and Flexbox with minmax() and clamp() for fluid typography and responsive columns. Navbar collapses to a hamburger drawer on screens under 900px.

Performance

Zero Build Step

No Webpack, Vite, or bundler required. Babel Standalone transpiles JSX directly in the browser at runtime. Fonts are loaded via Google Fonts CDN with font-display: swap.

Technology Stack

Core Technologies Used

Every library was chosen for zero-build compatibility — all loaded via CDN script tags.

  • React 18.3.1
    Declarative UI library used to build all components. Loaded via unpkg CDN with integrity hashes. Every page and shared component (Navbar, Footer, FadeUp, GradBtn, CountUp) is a React function component using hooks like useState, useEffect, and useRef.
  • ReactDOM 18.3.1
    Used to mount the root App component into the DOM via ReactDOM.createRoot(). This is the modern React 18 API that enables concurrent features and deferred rendering.
  • Babel Standalone 7.29.0
    Transpiles JSX syntax into plain JavaScript directly in the browser. All component files use type="text/babel" script tags. This eliminates any build tooling requirement while allowing modern JSX syntax throughout the project.
  • Custom Framer Motion Polyfill (framer-compat.js)
    A hand-written animation compatibility layer that mirrors the Framer Motion API — motion.div, motion.a, AnimatePresence, useInView, whileHover, whileTap, initial/animate props — using CSS transitions and IntersectionObserver. Written because the Framer Motion CDN was unavailable in the sandbox environment.
  • Inter (Google Fonts)
    Primary typeface loaded via Google Fonts. Weights 400, 500, 600, 700, and 800 are imported. Used for all body text, headings, labels, and UI elements across the entire site.
  • Vanilla JavaScript (ES2020)
    Used for all non-React interactivity: scroll progress bar updates, scroll-to-top button visibility, custom animated cursor tracking, IntersectionObserver-based section reveal animations, and hash-based routing via window.addEventListener('hashchange').
  • CSS3 (Inline + Global Stylesheet)
    All component-level styles are written as React inline style objects. Global styles (scrollbar, nav breakpoints, card mobile rules, reveal animations) are in a <style> block in index.html. CSS features used: Grid, Flexbox, clamp(), custom properties, @keyframes, @media queries, CSS gradients, backdrop-filter, and text-wrap: pretty.

Features & Implementation Patterns

Key Features Implemented

Each feature uses a specific browser API or React pattern explained below.

Routing

Hash-Based SPA Router

A custom useHash() hook listens to window.hashchange events and returns the current hash. The App component switches between page components based on the hash value, calling window.scrollTo(0,0) on every route change.

Animation

Scroll-Triggered Reveals

The FadeUp React component uses a custom useInView hook backed by IntersectionObserver. When the element enters the viewport, it transitions from opacity:0, translateY(40px) to fully visible — with configurable delay for staggered effects.

UX

Animated Custom Cursor

Two DOM elements (dot + ring) are positioned with position:fixed. The dot follows mouse coordinates instantly via mousemove. The ring uses a requestAnimationFrame loop with lerp (linear interpolation at 18% per frame) for a smooth trailing effect.

UX

Scroll Progress Bar

A fixed-position <div> at the top of the screen. Its width is updated on every scroll event using window.scrollY / (scrollHeight - innerHeight) × 100% — styled with a blue→purple→orange gradient and glow shadow.

UX

Scroll-to-Top Button

Appears after scrolling 320px using CSS class toggling (.visible). On click, calls window.scrollTo({ top: 0, behavior: 'smooth' }). Uses CSS transitions for the appear/disappear animation — no JS animation library needed.

Animation

CountUp Stat Animation

The CountUp component uses useInView to trigger a requestAnimationFrame loop when the stat enters the viewport. An ease-out cubic function (1 - (1-t)³) makes the number accelerate then slow to its final value.

Design system: Navy #0B0F2A · Brand Blue #1A4FA0 · Purple Accent #6C3FC5 · Soft Purple #9B72E8 · Orange #F5A623 — all used consistently across gradients, buttons, borders, and text highlights to create a cohesive visual language.
